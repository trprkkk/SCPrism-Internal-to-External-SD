# SCPrism-Internal-to-External-SD
Bind the SHINY COLORS Song for Prism game data from the internal SD to the external SD.

Required: Magisk or KernelSU etc.

For newer Android devices, you may need an sdcard access enabler.

https://github.com/Magisk-Modules-Alt-Repo/kaina
